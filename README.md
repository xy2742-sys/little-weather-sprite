# Little Weather

A tiny weather website with a tiny weather sprite. Pick a city and check in with your mood to see how Pip reacts to the combination.

## Try it

Open `index.html` in a browser. Choose a city and a mood; Pip changes its expression, message, and suggestion based on both selections. The “A tiny idea” button cycles through small activity prompts.

## About this sketch

- Built with HTML, CSS, and JavaScript.
- Uses sample weather data; it does not call a live weather service.
- Includes two user inputs (city and mood), state variables, event listeners, conditional logic, and visible feedback.

Made as an interactive design sketch about how the same weather can feel different depending on your mood.
